# Task

A specific actionable item that can be completed and is usually connected to a project, responsibility, or event.

**Use when:** something represents a concrete next action that needs to be performed and completed.

**Do not use when:** it's a large outcome requiring multiple actions (use [[Project]] instead), or general information, ideas, or decisions (use [[Note]] instead).
